# Safety and Content Boundaries

**Project:** ScenePilot

Related documents: [Product Contract](product-contract.md) · [MVP Scope](mvp-scope.md) · [Domain Glossary](domain-glossary.md)

These boundaries apply to all phases. They are product requirements, not optional guidelines.

---

## Link-processing boundaries

| Rule | Requirement |
|---|---|
| Permitted URLs only | Accept only public HTTP or HTTPS pages the user is authorized to use |
| Block private networks | Reject localhost, private IP ranges, and internal network targets |
| No social-video download | Do not download or ingest video files from social platforms |
| Untrusted content | Treat all extracted page content as untrusted user input |
| No prompt injection | Do not follow webpage instructions as system instructions |
| Resource limits | Cap response size, redirect count, and processing time |
| Sanitization | Strip scripts, hidden content, and unsafe markup from extracted text |

URL intake is implemented in Phase 17–18. Until then, URL fields may be collected but must not bypass these rules when processing is enabled.

---

## Copyright boundaries

| Rule | Requirement |
|---|---|
| No video reproduction | Do not reproduce copyrighted videos or frames |
| No clone instructions | Do not instruct users to replicate protected content exactly |
| No replication promises | Do not promise exact replication of another creator's work |
| Rights confirmation | Require users to confirm they have rights to submitted material |
| Inspiration only | Permit high-level thematic inspiration, not verbatim copying |

ScenePilot helps users create original plans. It is not a tool for duplicating existing copyrighted works.

---

## Identity and likeness boundaries

| Rule | Requirement |
|---|---|
| No deceptive impersonation | Do not facilitate content designed to deceive viewers about identity |
| Public-figure warnings | Warn users about celebrity and public-figure likeness restrictions on providers |
| No unauthorized voice cloning | Do not generate instructions to clone a person's voice without authorization |
| Private-person consent | Require explicit user acknowledgment for private-person likeness use |

These boundaries apply to **Continuity Bible** character locks and voiceover guidance.

---

## Accuracy boundaries

| Rule | Requirement |
|---|---|
| Preserve source facts | Factual claims from source material should be preserved, not altered |
| Mark unverified claims | Claims not supported by the source must be flagged |
| No invented specifications | Do not invent product specs, pricing, or features not in the source |
| Sensitive-topic warnings | Warn about medical, financial, legal, political, or safety-sensitive claims |

The **Prompt Quality Audit** should surface accuracy warnings where applicable.

---

## Product honesty

| Rule | Requirement |
|---|---|
| No generation claims | Never claim a video or image was generated by ScenePilot |
| No fake progress | Never display simulated rendering or generation progress bars |
| Plans, not media | Clearly state that outputs are plans, prompts, and instructions |
| Verified vs. assumed | Clearly separate verified provider capabilities from assumptions |

ScenePilot is an **AI Video Production Planner, Tool Recommendation Engine, and Prompt Compiler**. It does not produce media. All user-facing copy, loading states, and export headers must reflect this.

See [Product Contract — Product non-goals](product-contract.md#6-product-non-goals) for related boundaries.
